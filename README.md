# EduAI - Landing Page

## Definição do Problema (Letramento Digital)
No contexto atual, o **letramento digital** tornou-se uma necessidade básica para a inclusão social, acadêmica e profissional. No entanto, muitos estudantes, professores e instituições de ensino ainda enfrentam desafios na adoção e no uso produtivo de tecnologias, especialmente as baseadas em Inteligência Artificial.

O **EduAI** surge para resolver o problema da *falta de personalização no aprendizado* e da *desigualdade na fluência digital*. Como uma plataforma educacional interativa, o projeto visa:
1. **Para Alunos:** Democratizar o letramento digital, adaptando o ritmo e a complexidade do conteúdo ao perfil de cada estudante, reduzindo a frustração e a evasão.
2. **Para Professores:** Fornecer um assistente de IA que entrega insights detalhados sobre o desempenho da turma, otimizando o acompanhamento pedagógico.
3. **Para Instituições:** Modernizar a infraestrutura de ensino com uma ferramenta que prepara os alunos para o futuro digital.

Esta landing page tem como objetivo comunicar claramente esses pilares, atuando como a porta de entrada para a plataforma e convertendo visitantes em usuários engajados.

## Estrutura do Projeto (Refatoração)
A estrutura do projeto foi organizada visando escalabilidade e manutenção:

- `index.html`: Estrutura principal e semântica da página.
- `assets/`: Diretório contendo imagens, wireframes e recursos visuais (ex: `wireframe.webp`).
- `css/`: Nova arquitetura CSS modularizada.
  - `base/`
    - `reset.css`: Padronização de estilos entre navegadores.
    - `variables.css`: Design tokens (cores, fontes, espaçamentos).
  - `components/`: Estilos isolados para botões, cards, navbar.
  - `layout/`: Estilos para seções maiores (hero, footer).
